- We added X images of A and Y images of B.
- Most of the images were manually annotated.
- Initially, we trained the model on 10% of the dataset (200 images),
  balanced with 40 images per class, as an initial pilot.
- After demonstrating feasibility, we trained the model on the full dataset
  of 2,000 images.
- We integrated SAM to enable targeted, fine-grained blurring.
