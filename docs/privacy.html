Privacy Policy

Effective date: September 1, 2026

Overview

LeakLock is a Chrome extension that helps users review selected image uploads for sensitive visual content before an upload continues.

Information LeakLock Handles

When protection is enabled and you select an image for upload on a website, the extension sends that selected image file to the LeakLock analysis API at https://leaklock-api-799658247857.us-central1.run.app.

LeakLock also stores your on/off preference locally in Chrome extension storage.

LeakLock does not intentionally collect browsing history, cookies, authentication tokens, page text, typed form values, contacts, payment information, or account credentials.

How Information Is Used

Selected images are used only to provide LeakLock's image-risk analysis. The analysis checks for sensitive visual content such as faces, identity documents, documents, and license plates.

The extension displays the analysis result to you so you can choose whether to cancel the upload, continue the upload, or blur flagged image regions before continuing.

Sharing And Sale

LeakLock does not sell user data and does not use user data for personalized advertising, retargeting, credit decisions, or unrelated profiling.

Selected images are transferred to the LeakLock analysis API only as necessary to provide the extension's image-risk analysis.

Security

The extension transmits selected images to the LeakLock analysis API over HTTPS.

Retention

The LeakLock API processes selected images transiently for analysis and deletes the temporary uploaded image file after the request completes. The API may produce ordinary infrastructure logs needed to operate and secure the service.

Limited Use Disclosure

LeakLock's use of information received from Chrome extension users complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Contact

For support or privacy questions, open an issue at github.com/lior-benjman/LeakLock/issues.
