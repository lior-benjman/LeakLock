Chrome extension

LeakLock

Active image privacy protection that checks selected uploads for sensitive visual content before they are posted.

Chrome Web Store Privacy policy

Review image uploads before they continue.

Upload monitoring

LeakLock watches image file selections on normal web pages only when protection is enabled.

Risk analysis

Selected images are checked for sensitive content such as faces, identity documents, documents, and license plates.

Redaction option

When sensitive regions are flagged, LeakLock can blur those areas before the upload continues.

Privacy first, explicitly disclosed.

Protection is off by default. When enabled, images selected for upload are sent over HTTPS to the LeakLock analysis API for the extension's image-risk analysis.
