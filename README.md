# LeakLock
LeakLock

Download dataset from Roboflow using the API key snippet ! ! ! ! ! ! ! !
We added -600 QR / barcode images, 500 license plate images, 400 ID card images, 300 credit card images, 200 passport images. Total: ~2,000 images (YOLO-annotated).
All of the images were manually annotated.
Initially, we trained the model on 10% of the dataset (200 images), balanced with 40 images per class, as an initial pilot.
After demonstrating feasibility, we trained the model on the full dataset of 2,000 images.
We integrated SAM to enable targeted, fine-grained blurring.
