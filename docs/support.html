Support

Help and troubleshooting for the LeakLock Chrome extension.

Report a problem

Open an issue at github.com/lior-benjman/LeakLock/issues. Include the website where the upload was tested, the image type, and what you expected LeakLock to detect.

Before reporting

  • Open the LeakLock popup and confirm Protection is on.
  • Refresh the website after installing or updating the extension.
  • Use an ordinary HTTP or HTTPS page with a standard image file input.
  • Check whether the selected image is larger or unusually slow to analyze.
